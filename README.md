# 末日Q行 - 抖音小程序游戏

## 🎮 游戏简介
一个生存至100天的挑战游戏，玩家需要在末日世界中收集资源、组建团队、探索建筑物。

## 📁 项目结构 (模块化)

```
test0818/
├── game.js                    # 主游戏文件 (模块化重构版本)
├── game-modules/              # 模块化代码结构 (参考)
│   ├── character/            # 角色系统
│   ├── input/               # 输入系统
│   ├── collision/           # 碰撞检测
│   ├── camera/              # 摄像机系统
│   ├── building/            # 建筑系统
│   ├── npc/                 # NPC系统
│   ├── rendering/           # 渲染系统
│   ├── gamestate/           # 游戏状态管理
│   └── utils/               # 工具函数
├── game.json                # 游戏配置
├── project.config.json      # 项目配置
├── icon.png                 # 游戏图标
└── 游戏介绍.txt              # 游戏设计文档
```

## 🚀 核心功能

### ✅ 已实现的功能
- **摇杆控制** - 虚拟摇杆控制角色移动
- **角色系统** - 20个不同的角色，每个角色有独特外观
- **建筑交互** - 询问提示进入建筑，位置恢复机制
- **NPC系统** - 19个NPC可加入团队，智能跟随
- **碰撞检测** - 精确的建筑碰撞和团队移动检测
- **摄像机跟随** - 平滑跟随主角色
- **团队管理** - 团队成员协作移动和建筑探索

### 🎯 模块化优势
- **清晰的模块分离** - 每个功能模块职责明确
- **便于维护** - 代码结构清晰，易于修改和扩展
- **功能完整** - 保持所有原有功能不变
- **兼容性** - 完全兼容抖音小程序环境

## 🛠️ 开发说明

### 模块结构
- **角色系统**: 角色渲染、动画、管理
- **输入系统**: 摇杆控制、触摸事件处理
- **建筑系统**: 建筑生成、交互、进入/退出逻辑
- **NPC系统**: NPC管理、跟随逻辑、个性化行为
- **碰撞检测**: 建筑碰撞、团队移动检测
- **摄像机系统**: 摄像机跟随、视野管理
- **渲染系统**: 游戏渲染、UI渲染、场景渲染
- **状态管理**: 游戏状态切换、数据管理

### 扩展建议
- 新增建筑类型: 在建筑系统模块中添加
- 新增角色: 在角色系统模块中添加
- 新增功能: 在对应模块中添加，保持模块职责单一

## 🎲 游戏玩法
1. 使用摇杆控制角色移动
2. 靠近建筑门口会显示进入询问
3. 探索建筑获取资源
4. 收集NPC组建团队
5. 生存100天获得胜利
